IRI: https://w3id.org/smn/hasCycleLine

Relates a Conservation Unit, population, or stock whose age at return is invariant to the cycle line that constitutes it as a reproductive lineage.
This property makes the strong claim: the year series is closed under reproduction, so the line is a lineage and not merely a stratification. It is valid only where age at return is invariant — Pink Salmon, which return at age 2. Assigning a line to an individual fish is likewise only valid under that same invariance. Where age at return varies, as in Fraser Sockeye, use smn:stratifiedByCycleLine on the return-year record instead; a fish spawned on one line can return on another, so the class is not closed and the claim would be false.

Relates a named life-history type to its value on the juvenile rearing habitat axis: the kind of fresh water in which juveniles rear before migrating to sea.
A vocabulary-structure property, like smn:hasJuvenileFreshwaterResidenceDuration. IRI: https://w3id.org/smn/stratifiedByCycleLine

Relates a data record or observation carrying a return year to the cycle line that year falls in, as a stratification of the year series only.
The weak, always-safe claim: the subject year belongs to that residue class under the declared year basis.
