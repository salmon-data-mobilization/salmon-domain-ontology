## What changed, and where

- `scripts/verify_term_definitions.py` (new). A local term is an `smn:` IRI that
  a file in `ontology/modules/` types as an OWL class, object, datatype or
  annotation property, or as a SKOS concept or concept scheme. The check fails
  when such a term has no definition in the property its kind needs
  (`skos:definition` for SKOS, `obo:IAO_0000115` otherwise) and no row in the
  exemptions file. It also fails on a stale row, whose term now has a
  definition or is no longer local, and on a malformed row. It reads presence
  only. It runs a built-in fixture first, as `verify_method_shapes.py` does, and
  refuses to pass if it finds no local terms at all.
- `ontology/definition-exemptions.csv` (new). The file has two columns,
  `term,retired_by`. It is seeded with the 43 terms undefined on `d45f8f7`:
  `smn:NCBITaxon_8018` names B-108, `smn:Run` names B-237, and the other 41
  name B-232, as those cards assign them.
- `scripts/verify_year_age_semantic_contract.py`. `require_term_annotations()`
  now calls `has_definition()` from the new check instead of stating the rule
  again. Its now-unused `IAO_DEFINITION` constant went with the copy. Behaviour
  is unchanged; R1 and R2 below show it.
- `Makefile`. There is a new `verify-term-definitions` target in `make test`,
  so the check also runs in `make ci` and in both CI jobs that run either one:
  `validation` runs `make test`, and `publication-surface-drift-check` runs
  `make verify-generated-artifacts`, which runs `make ci`.
  `.github/workflows/ci.yml` needed no edit.
- `docs/annotation-gap-ledger.md`. Its hand-kept list of 43 undefined terms and
  its count are replaced by a pointer to the exemptions file, so that list has
  one home. The provenance list is untouched.
- `docs/entrypoints.md` and `README.md` list the new target.
  `knowledge/data/builds-and-import-graph.md`,
  `knowledge/data/owl-skos-conventions-state.md` and `knowledge/log.md` record
  the gate. The conventions card also records that the 43 now fall across
  modules 01/02/04/07.

## Retirement conditions of what this adds

- **The check** retires when a gate shared with smn's sibling vocabularies
  enforces the same per-kind rule over smn's local terms, which would make this
  repo-local copy redundant. The script's docstring says the same.
- **The exemptions file** retires when its last row does. B-232, B-237 and B-108
  each delete their rows in the change that defines or removes the term, and a
  stale row fails the build, so no row can outlive its gap.
